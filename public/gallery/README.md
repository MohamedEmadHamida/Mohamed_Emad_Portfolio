# Gallery (Render Wall)

Images for the infinite draggable wall on the homepage.

- Format: `.webp` (or `.jpg`), quality about 85
- Size: about 1600px on the long side. Cells are small, the focus card is at most ~900px wide
- Names: lowercase with dashes, e.g. `ferrero-rocher-macro.webp`
- After adding a file, add it to `renderWall` in `lib/content.ts` with a title, tag and one line

Aim for 25 to 30 images so the wall does not repeat too often.
