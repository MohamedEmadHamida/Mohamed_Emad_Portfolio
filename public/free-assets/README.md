# Free assets

Preview images for the "Free Assets & Tools" cards.

- Format: `.webp` (or `.jpg`), quality about 85
- Size: about 1600px wide. Cards are 4:3
- Names: the asset name, e.g. `rbd-fracture-hda.webp`
- After adding a file, set `image` on the asset in `lib/content.ts`. Without an image the card
  shows the generated gradient placeholder

Only previews go here. The downloadable files themselves (.hda, .zip, ...) go to file storage
in part 5, not into the repo.
