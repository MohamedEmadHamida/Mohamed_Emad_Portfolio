# Projects

Cover images for the "Selected Projects" cards (and later the project detail pages).

- Format: `.webp` (or `.jpg`), quality about 85
- Size: about 2000–2400px wide. Cards are 16:11, so keep the subject away from the edges
- Names: the project slug, e.g. `ferrero-rocher.webp`
- More images for one project (detail page, part 2): put them in a folder named after the slug,
  e.g. `ferrero-rocher/01.webp`, `ferrero-rocher/02.webp`
- After adding a file, set `image` on the project in `lib/content.ts`
